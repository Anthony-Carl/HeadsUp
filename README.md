### HeadsUp

Simple flutter project by [Anthony](https://github.com/Anthony-Carl).

## My project repository

Public repository: https://github.com/Anthony-Carl/HeadsUp/

## What it is

A dice rolling app created mainly for table-top game players that are short dice

## How to run it

1. clone the repository
2. run `flutter pub get`
3. run `flutter run` and select a device
